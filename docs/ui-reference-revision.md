## 2026-11-03 浅色主题更新

按用户确认的配色，将页面改为雾蓝灰背景 `#eff3f5`、暖白面板 `#fcfcfa`、石墨灰正文 `#282d32` 和深雾岛蓝主操作 `#476d83`。分类选中和悬停使用淡雾蓝 `#e1ecf2`，边框使用 `#d8e1e7`；原生表单采用浅色模式。图片及其深色标题遮罩不变。

本次只改颜色，保留布局、尺寸、间距、断点、动画与业务行为。Taste 对比问题 L-01 指出初稿辅助文字在页面背景上的对比度为 4.496:1，Impeccable 仅将辅助文字加深为 `#5e6b75`；错误文字改用 `#a23f38`。没有新增依赖或修改后端。

前端生产构建、lint 和类型检查通过，页面已更新至 3000 端口。固定视觉测试在 1440／768／390px 连续三轮通过（`artifacts/ui-light/V2`、`V3`、`V4`），每轮覆盖列表、制作、历史、空记录和读取错误；沿用同一版式，采用 V4 留档。三轮的主区域尺寸、位置、列宽和提交按钮底边均与上一版测量一致。已查看桌面、平板和手机截图，验证上传、详情展开、页面导航与减少动态效果设置。

### 修复空上传区域点击无响应

原文件输入框没有覆盖整个虚线框：定位范围限于内部内容区，且缺少完整高度。实测在已选择身份后点击左侧留白，未触发文件选择器。空状态现以整个 fieldset 为定位范围，让原生文件输入框覆盖完整区域；已上传状态仍只由“替换图片”触发选择，不遮挡移除和重试按钮。键盘焦点显示在整个空上传框外围，禁用状态使用禁用指针。

新增实际点击测试先复现旧版失败，再验证 1440／390px 的边缘留白、图标区域及下方留白能打开文件选择器，支持取消、上传、同文件替换和移除；未选择身份时不打开。另两项既有验证和键盘重试测试通过，共 4 项不同用例。生产构建、lint、类型检查通过，已查看两个尺寸的焦点截图（`artifacts/upload-click/`），页面已更新至 3000 端口。

## 依据与边界

原题 R-11 和 UI-01、UI-02、UI-03 决定主要布局。用户本轮授权修复已指出的偏差，并指定主题为石墨灰与雾岛蓝、增加适当动画。原有阶段五“定稿”仅保留为历史记录，不能作为本次 UI 完成结论。

## 初稿范围

- 列表：紧凑导航与分类，竖向图片卡片，标题和数量置于图底；移除占据首屏的宣传说明。
- 制作：左侧一体面板，内部依次是返回与标题、大幅示例、说明和素材要求、上传位、提交操作；右侧保留历史结果。
- 记录：统一媒体展示区；处理与失败状态在同一位置表达，成功展示图片；时间保留，技术 ID 和确认时间收进详情。
- 主题：石墨灰 `#191c20`、面板 `#22262b`、雾岛蓝 `#93b9cf`；错误使用独立语义颜色。
- 动效：封面轻微缩放、按钮按压与悬停、处理中旋转提示。遵循 prefers-reduced-motion，不用动画模拟任务进度。

在现有演示后端上使用临时前端预览和浏览器驱动检查，本次不新建独立数据库或交付环境。固定任务场景使用网络替身，仅用于可重复的视觉比较；真实操作另行检查。构建、检查和项目运行均在容器内。

### 检查过程中修正的测试假设

- 默认演示后端每步 3 秒，两条超时任务在数据库中分别约 9.19／9.13 秒成功；叠加查询间隔后超过原测试 10 秒等待窗口。增加可选 `PLAYWRIGHT_EXPECT_TIMEOUT_MS`，本次设为 25000，原隔离测试默认仍为 10000；应用耗时未调整。
- 正式构建中的隐藏表单节点会被无范围的标签定位器同时选中。上传辅助函数和相关键盘用例改为在可见“制作区域”内定位，不改业务行为。
- 返回控件已用 SVG 箭头和“返回模板库”无障碍名称，导航用例同步名称。
- 401 测试不再先断言短暂的已登录文案，而是选择身份后直接验证失效提示和清空结果，避免响应较快时产生时序误判。
