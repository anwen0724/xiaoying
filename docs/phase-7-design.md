先提交候选版本，再用 git archive 导出到 `artifacts/phase-7/source/`。导出不包含 node_modules、.next、target、.env 或运行数据。使用独立 Compose 项目 `xiaoying-acceptance`、新的 MySQL／文件卷和 3001 端口；现有演示服务保持运行。
