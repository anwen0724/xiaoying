## 5. 已知限制

- 服务重启后会话失效，内存队列中的非终态任务不恢复执行。已完成历史和文件持久化已验证；重建操作应在任务结束后进行。
- 模拟生成返回预置 SVG，不调用真实 AI，也不实际合成用户图片。
- 未实现账号注册、支付、任务取消、自动重试、提交幂等或素材清理；这些不是原题必做项。
- 文件与 MySQL 没有分布式事务，进程崩溃可能留下未引用文件。
- 浏览器验证使用容器 Chromium；未进行多浏览器或真实屏幕阅读器验收。
- 本轮 npm ci 仍报告 16 项中危依赖告警和 ESLint 维护提示；保留确认的依赖基线，没有在交付阶段顺带升级。生产依赖审计的旧结果仅按阶段六历史记录保留。
- 人工投入未单独计时。Git 和日志只记录工程过程，不估造人工总工时。
